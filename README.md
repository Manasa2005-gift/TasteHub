# 🍽️ TasteHub

## Online Food Ordering Website

TasteHub is a modern and responsive frontend food-ordering website designed to provide a simple and convenient online food-ordering experience.

Users can browse food items, search and filter the menu, add items to a shopping cart, manage quantities, and complete a checkout process.

## 🌐 Live Demo

👉 https://manasa2005-gift.github.io/TasteHub/

## 📌 Project Overview

The main goal of TasteHub is to create a simple and user-friendly food-ordering platform.

The website provides an interactive interface where users can explore food items, manage their cart, enter delivery details, and receive an order confirmation.

## ✨ Features

- Premium and responsive user interface
- Food menu with multiple items
- Food search functionality
- Category-based food filtering
- Add to Cart functionality
- Increase and decrease item quantity
- Remove items from cart
- Automatic subtotal calculation
- Delivery charge calculation
- Grand total calculation
- LocalStorage cart persistence
- Checkout form validation
- Indian 10-digit phone number validation
- Payment method selection
- Order ID generation
- Order confirmation
- Estimated delivery time
- Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub Pages

## 💾 LocalStorage

TasteHub uses browser LocalStorage to save the shopping cart.

This allows the selected cart items to remain available even after refreshing the webpage.

## 💳 Payment

The project currently demonstrates the payment-selection interface only.

It does not use a real payment gateway because this is a frontend-only project.
